# Stack Solve Task Manager

A modern command-line Todo Manager built using Python and MongoDB.

Created by Ritesh.

## Features

- Create Tasks
- View All Tasks
- Update Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Filter by Priority
- Sort Tasks
- Favorite Important Tasks
- View Favorite Tasks
- Task Statistics
- Delete All Tasks
- MongoDB Database Integration
- Clean CLI Experience
- Real-Time Data Storage

## Tech Stack

- Python
- MongoDB
- PyMongo
